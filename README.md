# Memo · TT版 1.0.12

安装地址：https://github.com/cszgezi-lab/Memo-TT

面向 TauriTavern 2.2。安装并打开 Memo，在设置中填写总结、动态人设、向量和重排连接；新安装的自动总结与自动人设默认关闭，按需要在总览开启。原版拾忆仍从原地址使用，新旧版本的配置、Key、存档和注入标识独立；同一聊天请只启用其中一个版本。

设置“标签管理”复用提取/排除规则，用于总结与人设读取选中的聊天正文，支持 XML 块和正则预览，不修改聊天原文。普通召回中的原文依据不会重新套用当前过滤规则。日志页集中导出日志、纯配置和当前聊天备份；API Key 不进入导出。头像保存在本设备界面存储，不进入模型请求和聊天备份。

总结、人物、字典、向量、重排和最终注入使用原版生产引擎；世界信息、知识库和助手独立功能不再提供。动态人设仍可只读核对角色卡和已绑定世界书，并在当前请求中替换对应人物，不改原书正文。

本地协议模型与隔离宿主用于验证接口联动；真实模型语义与 Android 实机效果需分别验收。浏览器只提示派发下载时，请确认文件实际保存。

主总结、修复复核及动态人设采用流式传输，收到完整回复并通过原有校验后才保存；中断和错误不会作为成功结果落地。已知渠道错误会尽早结束等待，恢复仍受现有次数上限、限流与冷却约束。主总结预设新增“破甲区”：反截断开关和可编辑破甲词；已取消头部及用户输入长填充，旧预设中的填充开关不再发送这两段文本，保存后生效。破甲词计入预算，工具参数与记忆完整性仍严格校验；这些选项不能保证解决服务商截断或限流。兼容工具及填充文本的 MIT 署名见 LICENSE.txt。
